Stock Portfolio Analyzer: Architecture

A Streamlit app (app.py) that only draws screens, on top of a portfolio/ package that does all the calculations. It runs locally with uv and Python 3.12.

How data flows

  1. Upload. In Tab 1 you upload a CSV, load the sample or fill in the manual form.
  2. Validate. loader.normalize_transactions maps column names (for example ticker to symbol), checks every row and reports bad CSV lines.
  3. Save. Valid rows go into st.session_state.tx and are written to data/transactions.csv, so they survive a restart.
  4. Replay trades. holdings.compute_positions goes through the trades in date order and works out the quantity, average cost and realized profit for each stock.
  5. Price. prices.current_prices gets live closing prices from yfinance (cached for 15 minutes). For any stock it can't price, it uses the last trade price.
  6. Measure. performance.performance_summary works out the lifetime totals and xirr. value_over_time combines daily holdings with the price history (cached for 60 minutes).
  7. Render. Tab 2 shows the allocation pie and the Stock Price Breakdown table. Tab 3 shows the six metrics and the trend line.

Key rules

  • Average-cost method: a sale removes cost at the average cost per share, and realized profit = (sale price − average cost) × shares sold. A sale larger than the shares held is reduced to the shares held.
  • Price fallback: if there's no live price, the last trade price is used. The holdings table shows which source each price came from.
  • Consistency check: Total Return = realized profit + unrealized profit (Lifetime Proceeds − Total Lifetime Investment). A test checks this.
